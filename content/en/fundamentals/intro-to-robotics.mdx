# Introduction to Autonomous Robotics & Classifications

> "A robot is neither simply a computer on wheels nor an automatic mechanical gadget. A robot is an embodied physical intelligence that senses, reasons, and actively transforms the real world in a closed-loop."

**Robotics** is the interdisciplinary science bridging mechanical engineering, electrical engineering, computer science, mathematics, and artificial intelligence to create autonomous physical machines.

---

## 1. Cyber-Physical Systems Anatomy

An autonomous robot operates across four foundational interconnected subsystems:

```text
┌───────────────────────────────┐
│     PHYSICAL ENVIRONMENT      │
└───────────────────────────────┘
     │                    ▲
     │ (Photons / Forces) │ (Torque / Velocity)
     ▼                    │
┌──────────────┐     ┌──────────────┐
│ 1. SENSORS   │     │ 4. ACTUATORS │
│ (Eyes / Ears)│     │(Motors/Limbs)│
└──────────────┘     └──────────────┘
     │                    ▲
     ▼                    │
┌───────────────────────────────────┐
│ 2. STATE ESTIMATION & PERCEPTION  │
│ 3. PLANNING & FEEDBACK CONTROL    │
│      (Robotic Compute Core)       │
└───────────────────────────────────┘
```

1. **Sensors (*Sensing*)**: Proprioceptive sensors (wheel encoders, IMU, motor current) and exteroceptive sensors (LiDAR, RGB-D cameras, radar, sonar) transduce physical phenomena into digital measurements.
2. **State Estimation & Perception**: Filters noisy raw measurements into consistent spatial beliefs $\mathbf{x} = [x, y, \theta]^T$ and spatial representations (Occupancy Grids / OctoMaps).
3. **Planning & Decision-Making**: Computes collision-free dynamically feasible paths from start configurations to goal targets.
4. **Actuators (*Actuation*)**: Converts compute commands into mechanical torque $\tau$, rotational velocity $\omega$, and linear thrust $F$.

## 3. Robot Morphology Taxonomy

Robots are classified into 5 primary physical embodiments based on their workspace topology and degrees of freedom (DOF):

<RobotClassificationExplorer />

```text
┌─────────────────────────┬──────────────┬─────────────────────────────┬────────────────────────────────────────────────────────┐
│ Robot Morphology        │ Workspace    │ Core Sensor Suite           │ Primary Engineering Challenges                         │
├─────────────────────────┼──────────────┼─────────────────────────────┼────────────────────────────────────────────────────────┤
│ 1. Wheeled Mobile (AMR) │ 2D Plane     │ 2D LiDAR, Wheel Encoders    │ Wheel slippage, indoor localization, non-holonomy      │
│ 2. Serial Manipulator   │ 3D Envelope  │ Joint Encoders, Hand Camera │ Inverse kinematics, Jacobian singularities, payload    │
│ 3. Aerial Drone (UAV)   │ 3D Volumetric│ 1000Hz IMU, Barometer, RGB-D│ Flight endurance, rapid aerodynamics, payload limits   │
│ 4. Marine (AUV / USV)   │ 3D Aquatic   │ Multibeam Sonar, DVL, IMU   │ Acoustic attenuation, absence of underwater GPS        │
│ 5. Legged (Humanoid/Dog)│ Dynamic 3D   │ IMU, Foot Force/Torque      │ Zero Moment Point (ZMP) stability, contact physics     │
└─────────────────────────┴──────────────┴─────────────────────────────┴────────────────────────────────────────────────────────┘
```
