# A* vs. Dijkstra Search: Heuristics & Exploration Wavefronts (M15)

> "Why does A* expand significantly fewer nodes than Dijkstra's algorithm while still guaranteeing the mathematically optimal shortest path?"

Graph path planning algorithms find collision-free paths from a Start node $S$ to a Goal node $G$. The core difference between Dijkstra's algorithm and A* lies in the **cost evaluation function $f(n)$**.

---

## 1. Mathematical Cost Formulations: $f(n) = g(n) + h(n)$

For any node $n$ on the grid:

$$
f(n) = g(n) + h(n)
$$

Where:
- **$g(n)$ (Past Cost)**: The exact shortest path cost accumulated from the start node $S$ to node $n$.
- **$h(n)$ (Heuristic Estimate)**: An admissible estimate of the remaining cost from node $n$ to the goal $G$.
- **$f(n)$ (Estimated Total Cost)**: The priority key used to sort nodes in the open set Priority Queue.

### The Fundamental Bridge Theorem
$$
\text{If } h(n) = 0 \quad \forall n \implies f(n) = g(n) \equiv \text{Dijkstra's Algorithm}
$$

Dijkstra expands nodes strictly in concentric circles of increasing distance $g(n)$, exploring blindly in all 360° directions. A* uses $h(n)$ to pull the search wavefront directly towards the goal.

---

## 2. Heuristic Taxonomy on 2D Grids

| Heuristic | Formula | Connectivity | Properties |
|---|---|---|---|
| **Dijkstra** | $h(n) = 0$ | Any | Blind uniform expansion, guaranteed optimal |
| **Manhattan** | $h(n) = 10 \cdot (|\Delta x| + |\Delta y|)$ | 4-Connected | Admissible for 4-way grid motions |
| **Euclidean** | $h(n) = 10 \cdot \sqrt{\Delta x^2 + \Delta y^2}$ | Any / Continuous | Admissible for straight line-of-sight |
| **Octile** | $h(n) = 10(\Delta x + \Delta y) - 6\min(\Delta x, \Delta y)$ | 8-Connected | Tightly admissible for 8-way diagonal grids |

### Admissibility Condition
A heuristic is **admissible** if it never overestimates the true remaining cost to the goal:

$$
h(n) \le h^*(n) \quad \forall n
$$
