# A* Path Planning on 2D Grids & Heuristic Graph Search

> "How can a robot find the shortest collision-free path across millions of grid cells without searching every single possibility blindly?"

In autonomous robotics, path planning is the process of computing a continuous collision-free trajectory from a start position $\mathbf{x}_{\text{start}}$ to a goal destination $\mathbf{x}_{\text{goal}}$ through an obstacle-cluttered configuration space $\mathcal{C}_{\text{free}}$.

---

## 1. Graph Search Formulation

The robot's workspace is discretized into a 2D occupancy grid graph $G = (V, E)$, where:
- $V$: Vertices representing navigable grid cells $(x, y)$.
- $E$: Edges representing traversable transitions between neighboring cells (4-connected orthogonal or 8-connected diagonal movements).

---

## 2. The A* Evaluation Function

Dijkstra's algorithm searches outward uniformly in all directions. A* dramatically accelerates the search toward the goal by evaluating each candidate node $n$ with an **Evaluation Function** $f(n)$:

$$
f(n) = g(n) + h(n)
$$

### Components:
- **$g(n)$**: The **exact known cost** incurred to travel from the start node $\mathbf{x}_{\text{start}}$ to node $n$.
- **$h(n)$**: The **heuristic estimate** of the remaining cost from node $n$ to the goal $\mathbf{x}_{\text{goal}}$.
- **$f(n)$**: The estimated total cost of the cheapest path constrained to pass through node $n$.

---

## 3. Admissibility & Consistency Conditions

For A* to guarantee finding the **strictly optimal shortest path**:

### 1. Admissibility ($h(n) \le h^*(n)$)
The heuristic $h(n)$ must **never overestimate** the true remaining cost $h^*(n)$ to reach the goal.

### 2. Consistency (Triangle Inequality)
For every node $n$ and neighbor $n'$ with step cost $c(n, n')$:

$$
h(n) \le c(n, n') + h(n')
$$

---

## 4. Standard Distance Heuristics

Depending on the allowed motion connections on the grid:

### Euclidean Distance ($L_2$ norm):
Used when the robot can rotate and translate in any arbitrary angle:

$$
h_{\text{euclidean}}(n) = \sqrt{(x_n - x_g)^2 + (y_n - y_g)^2}
$$

### Manhattan Distance ($L_1$ norm):
Used for 4-connected grid movements (Up, Down, Left, Right only):

$$
h_{\text{manhattan}}(n) = |x_n - x_g| + |y_n - y_g|
$$

### Octile Distance (8-connected grid with diagonal cost $\sqrt{2}$):
$$
h_{\text{octile}}(n) = (\Delta x + \Delta y) + (\sqrt{2} - 2)\min(\Delta x, \Delta y)
$$

where $\Delta x = |x_n - x_g|$ and $\Delta y = |y_n - y_g|$.

## 6. Mathematical Algorithm to Code Bridge

```typescript
function aStar(start: Node, goal: Node, grid: Grid): Node[] {
  const openSet = new PriorityQueue<Node>((a, b) => a.f - b.f);
  start.g = 0;
  start.f = start.g + heuristic(start, goal);
  openSet.insert(start);

  while (!openSet.isEmpty()) {
    const current = openSet.popMin();
    if (current.equals(goal)) return reconstructPath(current);

    for (const neighbor of grid.getNeighbors(current)) {
      const tentativeG = current.g + distance(current, neighbor);
      if (tentativeG < neighbor.g) {
        neighbor.parent = current;
        neighbor.g = tentativeG;
        neighbor.f = neighbor.g + heuristic(neighbor, goal);
        if (!openSet.contains(neighbor)) openSet.insert(neighbor);
      }
    }
  }
  return []; // No path found
}
```
