# k-Means Point Cloud Obstacle Object Clustering

> "How does an autonomous robot separate thousands of unstructured laser return points into distinct physical objects such as vehicles, pedestrians, or structural pillars?"

In advanced robotic spatial perception, an autonomous system cannot treat point returns in isolation. It must group spatial point sets into discrete **obstacle entities (point cloud segmentation)**. The **$k$-Means Clustering** algorithm provides an unsupervised learning framework that partitions an unorganized set of $N$ laser points $\mathcal{P} = \{\mathbf{p}_1, \dots, \mathbf{p}_N\}$ into $K$ distinct clusters by minimizing within-cluster variance.

## 1. Mathematical Objective Function

The objective of $k$-Means is to find an optimal partition of $K$ cluster sets $\mathcal{C} = \{C_1, C_2, \dots, C_K\}$ and their corresponding centroids $\boldsymbol{\mu}_k$ that minimizes the Within-Cluster Sum of Squares (WCSS):

$$
J = \sum_{k=1}^K \sum_{\mathbf{p}_i \in C_k} \|\mathbf{p}_i - \boldsymbol{\mu}_k\|^2
$$

### The Two-Stage Iterative Cycle (Expectation-Maximization):

1. **Assignment Step**:
   Assign each point $\mathbf{p}_i$ to its closest centroid (forming Voronoi partition boundaries):
   $$
   C_k^{(t)} = \left\{ \mathbf{p}_i \mid \|\mathbf{p}_i - \boldsymbol{\mu}_k^{(t)}\|^2 \le \|\mathbf{p}_i - \boldsymbol{\mu}_j^{(t)}\|^2, \quad \forall j \in \{1, \dots, K\} \right\}
   $$

2. **Centroid Update Step**:
   Recompute the arithmetic mean (center of mass) of all points belonging to cluster $k$:
   $$
   \boldsymbol{\mu}_k^{(t+1)} = \frac{1}{|C_k^{(t)}|} \sum_{\mathbf{p}_i \in C_k^{(t)}} \mathbf{p}_i
   $$

The algorithm terminates when centroid displacement satisfies $\|\boldsymbol{\mu}_k^{(t+1)} - \boldsymbol{\mu}_k^{(t)}\| < \epsilon$ (convergence).
