# Zero Moment Point (ZMP), Linear Inverted Pendulum & Legged Locomotion

> "Why don't bipedal humanoid robots and quadrupedal robots topple over while walking dynamically on uneven ground, and what makes the Zero Moment Point (ZMP) the universal mathematical criterion for dynamic balance?"

Unlike wheeled mobile robots which maintain a permanently stable base of support, legged robots are **periodically underactuated and hybrid dynamical systems**. During walking, foot contacts make and break collision impacts intermittently. Maintaining upright dynamic equilibrium without tipping requires continuously steering the **Zero Moment Point (ZMP)** inside the **Support Polygon**.

## 1. The Zero Moment Point (ZMP) Physical Definition

The **Zero Moment Point (ZMP)** $\mathbf{p}_{\text{ZMP}} = [x_{\text{ZMP}}, y_{\text{ZMP}}, 0]^T$ is the unique spatial point on the ground plane where the total horizontal moment generated by gravitational, inertial, and inertial acceleration forces equals **strictly zero**:

$$
\tau_x(p_{\text{ZMP}}) = 0, \quad \tau_y(p_{\text{ZMP}}) = 0
$$

For a multi-link robot with $N$ rigid links where each link has mass $m_i$, position $\mathbf{r}_i = [x_i, y_i, z_i]^T$, and linear acceleration $\ddot{\mathbf{r}}_i = [\ddot{x}_i, \ddot{y}_i, \ddot{z}_i]^T$:

$$
x_{\text{ZMP}} = \frac{\sum_{i=1}^N m_i (\ddot{z}_i + g) x_i - \sum_{i=1}^N m_i \ddot{x}_i z_i - \sum_{i=1}^N I_{y,i} \dot{\omega}_{y,i}}{\sum_{i=1}^N m_i (\ddot{z}_i + g)}
$$

$$
y_{\text{ZMP}} = \frac{\sum_{i=1}^N m_i (\ddot{z}_i + g) y_i - \sum_{i=1}^N m_i \ddot{y}_i z_i + \sum_{i=1}^N I_{x,i} \dot{\omega}_{x,i}}{\sum_{i=1}^N m_i (\ddot{z}_i + g)}
$$

### The Golden Stability Criterion:
A legged robot is dynamically stable and will **not tip over** if and only if the calculated ZMP remains strictly inside the convex hull of the foot ground contact area (**Support Polygon $\mathcal{S}$**):

$$
\mathbf{p}_{\text{ZMP}} \in \text{interior}(\mathcal{S})
$$

If the ZMP reaches the boundary $\partial \mathcal{S}$, the foot begins to pivot around the edge, and the robot tips into uncontrolled falling.

## 2. The Linear Inverted Pendulum Model (LIPM)

Computing multi-body ZMP equations in real time across 30+ actuators is computationally intense. In 2001, Shuuji Kajita introduced the **Linear Inverted Pendulum Model (LIPM)** by constraining the Center of Mass (CoM) to move along a constant horizontal plane of height $z_c$:

```text
       (CoM Mass m)
          ● [x, z_c]
         / \
        /   \ 
       /     \  Height z_c = const
      /       \
     /         \
    O───────────O (Ground Plane)
 [x_ZMP]
```

Under the constant height constraint $\ddot{z} = 0$, the non-linear 3D pendulum dynamics collapse into an elegant **linear, decoupled ordinary differential equation**:

$$
\ddot{x} = \frac{g}{z_c} (x - x_{\text{ZMP}}) = \omega_0^2 (x - x_{\text{ZMP}})
$$

Where $\omega_0 = \sqrt{g / z_c}$ represents the natural orbital frequency of the walking pendulum.

## 3. Quadruped Gait Taxonomy: Walk, Trot, Pace, Gallop

For 4-legged robots (e.g., Boston Dynamics Spot, ANYmal, Unitree Go2), locomotion is categorized by relative leg phase offsets $\phi_i \in [0, 1)$:

```text
┌─────────────────┬──────────────────────┬──────────────────────┬────────────────────────────────────────────────────────┐
│ Gait Type       │ Duty Factor (beta)   │ Leg Phase Timing     │ Dynamic Characteristics & Stability                    │
├─────────────────┼──────────────────────┼──────────────────────┼────────────────────────────────────────────────────────┤
│ Static Walk     │ beta > 0.75          │ 1 leg swings at once │ Statically stable (3 legs form triangular polygon)     │
│ Trot            │ beta = 0.50          │ Diagonal pairs (LF+RH)│ Dynamically stable (requires continuous ZMP feedback)  │
│ Pace            │ beta = 0.50          │ Lateral pairs (LF+LH)│ Lateral rolling oscillation (common in camels)         │
│ Gallop / Bound  │ beta < 0.35          │ Front then Rear pair │ High-speed ballistic flight phases (aerial leap)       │
└─────────────────┴──────────────────────┴──────────────────────┴────────────────────────────────────────────────────────┘
```
