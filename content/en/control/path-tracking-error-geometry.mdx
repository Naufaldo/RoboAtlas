# Path Tracking Error Geometry: Cross-Track & Heading Errors (M14)

> "Before an autonomous vehicle can steer, it must know: How far off the centerline am I, and by what angle is my nose pointing away from the curve?"

Path tracking controllers (such as Pure Pursuit, Stanley, and Model Predictive Control) rely on two fundamental error metrics: **Cross-Track Error ($e_{\text{lat}}$)** and **Heading Alignment Error ($e_\theta$)**.

---

## 1. Reference Path Representation & Frenet-Serret Frame

Let a planned 2D geometric path be parameterized by arc length $s$:

$$
\mathbf{r}(s) = \begin{bmatrix} x_r(s) \\ y_r(s) \end{bmatrix}
$$

At each arc length point $s$, the path defines an orthonormal **Frenet-Serret frame**:
- **Unit Tangent Vector $\hat{\mathbf{t}}(s)$**:
  $$
  \hat{\mathbf{t}}(s) = \frac{d\mathbf{r}/ds}{\|d\mathbf{r}/ds\|} = \begin{bmatrix} \cos\theta_{\text{path}}(s) \\ \sin\theta_{\text{path}}(s) \end{bmatrix}
  $$
- **Unit Normal Vector $\hat{\mathbf{n}}(s)$** (pointing leftward of path tangent):
  $$
  \hat{\mathbf{n}}(s) = \begin{bmatrix} -\sin\theta_{\text{path}}(s) \\ \cos\theta_{\text{path}}(s) \end{bmatrix}
  $$

---

## 2. Derivation: Closest Point, Cross-Track & Heading Errors

Given current robot front-axle/center position $\mathbf{p} = [x, y]^T$ and yaw heading $\theta$:

### 2.1 Closest Point Search on Path
The closest path coordinate $s^*$ minimizes Euclidean distance:

$$
s^* = \arg\min_s \|\mathbf{p} - \mathbf{r}(s)\|
$$

### 2.2 Cross-Track Lateral Error ($e_{\text{lat}}$)
The signed perpendicular distance from the path centerline to the robot is the scalar projection of $(\mathbf{p} - \mathbf{r}(s^*))$ onto the unit normal $\hat{\mathbf{n}}(s^*)$:

$$
e_{\text{lat}} = (\mathbf{p} - \mathbf{r}(s^*)) \cdot \hat{\mathbf{n}}(s^*) = -(x - x_r)\sin\theta_{\text{path}} + (y - y_r)\cos\theta_{\text{path}}
$$

*(Positive $e_{\text{lat}}$ indicates the robot is to the left of the path; negative indicates right).*

### 2.3 Heading Alignment Error ($e_\theta$)
The angular difference between robot heading and path tangent orientation:

$$
e_\theta = \theta - \theta_{\text{path}}(s^*)
$$

*(Normalized to the interval $[-\pi, +\pi]$).*
