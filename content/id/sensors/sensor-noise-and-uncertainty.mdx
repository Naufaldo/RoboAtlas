# Model Derau Sensor, Ketidakpastian Gaussian & Kerapatan Probabilitas (M08)

> "Tidak ada sensor fisik di dunia nyata yang 100% sempurna. Bagaimana cara memodelkan derau pengukuran secara matematis agar robot mampu membedakan kondisi sebenarnya dari sinyal palsu?"

Dalam robotika dunia nyata, sensor (LiDAR, ultrasonik, enkoder optik roda, IMU, GPS) selalu terpapar fluktuasi termal acak, galat kuantisasi digital, dan gangguan lingkungan fisik.

---

## 1. Model Pengukuran Aditif

Hubungan antara status posisi fisik sebenarnya $x$ dan nilai pembacaan sensor $z$ dimodelkan sebagai:

$$
z = h(x) + b + \epsilon
$$

Di mana:
- $h(x)$ adalah fungsi pengukuran fisik ideal.
- $b$ adalah **bias sistematik** konstan (galat pergeseran titik nol / *offset error*).
- $\epsilon \sim \mathcal{N}(0, \sigma^2)$ adalah **derau acak Gaussian** dengan rata-rata nol dan variansi $\sigma^2$.

---

## 2. Penurunan Rumus: Fungsi Kerapatan Probabilitas Gaussian (PDF)

Berdasarkan **Teorema Limit Pusat (*Central Limit Theorem*)**, gabungan berbagai sumber derau mikroskopis acak terakumulasi menjadi kurva distribusi normal (Gaussian):

$$
p(z \mid x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(z - h(x) - b)^2}{2\sigma^2} \right)
$$

### Statistik Sampel (Estimasi Empiris)
Dari $N$ data sampel sensor yang tercatat $z_1, z_2, \dots, z_N$:

$$
\begin{aligned}
\text{Rata-rata Sampel } \bar{z} &= \frac{1}{N} \sum_{i=1}^N z_i \\
\text{Variansi Sampel } s^2 &= \frac{1}{N-1} \sum_{i=1}^N (z_i - \bar{z})^2
\end{aligned}
$$

### Interval Kepercayaan (*Empirical Rule*):
- **Tingkat Keyakinan $1\sigma$**: $68.27\%$ sampel berada pada rentang $[\mu - \sigma, \mu + \sigma]$.
- **Tingkat Keyakinan $2\sigma$**: $95.45\%$ sampel berada pada rentang $[\mu - 2\sigma, \mu + 2\sigma]$.
- **Tingkat Keyakinan $3\sigma$**: $99.73\%$ sampel berada pada rentang $[\mu - 3\sigma, \mu + 3\sigma]$.
