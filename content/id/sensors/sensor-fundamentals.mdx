# Fundamental Sensor, Model Pengukuran & Derau Gaussian

> "Bagaimana robot fisik mengamati dunia nyata ketika setiap perangkat sensor perangkat keras memiliki ketidakpastian pengukuran yang tak terhindarkan?"

Tanpa sensor, sebuah mesin otonom ibarat berjalan dalam kebutaan. Sensor bertugas mengonversi fenomena fisik lingkungan (seperti foton cahaya, gelombang akustik suara, medan magnet, dan putaran roda) menjadi sinyal data numerik digital.

---

## 1. Sensor Eksteroseptif vs. Proprioseptif

Robotika mengklasifikasikan perangkat keras sensor ke dalam dua kategori utama:

1. **Sensor Proprioseptif**: Mengukur status internal dari robot itu sendiri (seperti enkoder optik roda, sensor arus motor, potensiometer sendi, dan giroskop IMU).
2. **Sensor Eksteroseptif**: Mengukur fitur lingkungan eksternal (seperti LiDAR 2D/3D, sonar ultrasonik, kamera stereo, dan sensor kedalaman inframerah).

---

## 2. Model Derau Pengukuran Gaussian

Tidak ada sensor fisik yang 100% sempurna. Ketika pemindai LiDAR mengukur jarak $z_t$ ke dinding rintangan pada jarak sebenarnya $d_{\text{true}}$, hasil pembacaan dipengaruhi oleh derau acak Gaussian aditif $\epsilon \sim \mathcal{N}(0, \sigma^2)$:

$$
z_t = d_{\text{true}} + \epsilon
$$

Fungsi kerapatan probabilitas bersyarat (*Probability Density Function / PDF*) yang merepresentasikan kemungkinan pengukuran sensor adalah:

$$
p(z_t \mid d_{\text{true}}) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(z_t - d_{\text{true}})^2}{2\sigma^2} \right)
$$

Di mana:
- **$z_t$**: Nilai jarak terukur oleh sensor $[\text{m}]$
- **$d_{\text{true}}$**: Jarak rintangan sebenarnya $[\text{m}]$
- **$\sigma$**: Standar deviasi derau sensor $[\text{m}]$ ($\sigma^2$ adalah variansi pengukuran)
