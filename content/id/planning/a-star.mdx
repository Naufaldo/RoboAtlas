# Perencanaan Jalur A* pada Grid 2D

Algoritma pencarian A* menemukan jalur terpendek optimal pada ruang graf dengan memprioritaskan simpul yang memiliki estimasi total biaya terendah.

## Fungsi Evaluasi Biaya

$$f(n) = g(n) + h(n)$$

- $g(n)$: Biaya aktual yang sudah ditempuh dari titik awal ke simpul $n$.
- $h(n)$: Estimasi jarak heuristik sisa dari simpul $n$ ke titik tujuan goal.

## Heuristik Octile Admisibel

$$h_{octile}(n) = (\Delta x + \Delta y) + (\sqrt{2} - 2)\min(\Delta x, \Delta y)$$
