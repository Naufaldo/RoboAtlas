# Pengantar Robotika Otonom & Klasifikasinya

> "Robot bukan sekadar komputer yang dipasangi roda, dan bukan sekadar mesin mekanis otomatis. Robot adalah entitas fisik cerdas yang mengamati, bernalar, dan mengubah keadaan dunia nyata secara simpal tertutup (closed-loop)."

**Robotika** adalah ilmu interdisipliner yang menggabungkan teknik mesin, teknik elektro, ilmu komputer, matematika, dan kecerdasan buatan untuk merancang mesin fisik otonom.

---

## 1. Anatomi Sistem Siber-Fisik (*Cyber-Physical Systems*)

Sebuah robot otonom tersusun atas empat pilar subsistem utama:

```text
┌───────────────────────────────┐
│     LINGKUNGAN FISIK NYATA    │
└───────────────────────────────┘
     │                    ▲
     │ (Fisika/Cahaya)    │ (Torsi/Gaya)
     ▼                    │
┌──────────────┐     ┌──────────────┐
│ 1. SENSOR    │     │ 4. AKTUATOR  │
│ (Mata/Telinga)│    │ (Otot/Motor) │
└──────────────┘     └──────────────┘
     │                    ▲
     ▼                    │
┌───────────────────────────────────┐
│ 2. ESTIMASI STATUS & PEMETAAN     │
│ 3. PERENCANAAN & KENDALI CERDAS   │
│       (Komputasi Otak Robot)      │
└───────────────────────────────────┘
```

1. **Sensor (*Sensing*)**: Sensor proprioseptif (enkoder roda, IMU, arus motor) dan sensor eksteroseptif (LiDAR, Kamera RGB-D, Radar, Sonar) mengubah fenomena fisika menjadi sinyal digital.
2. **Estimasi Status & Persepsi (*Perception*)**: Mengolah data sensor berderau menjadi keyakinan status posisi robot $\mathbf{x} = [x, y, \theta]^T$ dan model lingkungan (Peta Okupansi / OctoMap).
3. **Perencanaan & Pengambilan Keputusan (*Planning*)**: Menghitung trajektori trajektori optimal bebas rintangan dari titik awal ke tujuan.
4. **Aktuator (*Actuation*)**: Mengubah tegangan listrik PWM dan arus motor menjadi torsi mekanis $\tau$, kecepatan putar $\omega$, dan gaya dorong $F$.

## 3. Taksonomi Morfologi Robotika

Berdasarkan lingkungan operasional dan derajat kebebasannya (*Degrees of Freedom / DOF*), robot diklasifikasikan ke dalam 5 famili utama:

<RobotClassificationExplorer />

```text
┌─────────────────────────┬──────────────┬─────────────────────────────┬────────────────────────────────────────────────────────┐
│ Famili Robot            │ Ruang Kerja  │ Sensor Tipikal              │ Tantangan Utama                                        │
├─────────────────────────┼──────────────┼─────────────────────────────┼────────────────────────────────────────────────────────┤
│ 1. Wheeled Mobile (AMR) │ Bidang 2D    │ 2D LiDAR, Enkoder, Wheel IMU│ Selip roda, lokalisasi indoor, kendala non-holonomik   │
│ 2. Serial Manipulator   │ Ruang 3D     │ Enkoder Sendi, Kamera Hand  │ Kinematika balik, singularitas Jacobian, torsi beban   │
│ 3. Aerial Drone (UAV)   │ 3D Volumetrik│ IMU 1000Hz, Barometer, RGB-D│ Daya tahan baterai, aerodinamika cepat, batasan bobot  │
│ 4. Marine (AUV / USV)   │ Akuatik / 3D │ Sonar Multibeam, DVL, IMU   │ Redaman air, ketiadaan GPS di bawah laut, turbulensi   │
│ 5. Legged (Humanoid/Dog)│ Dinamis 3D   │ IMU, Sensor Torsi Kaki      │ Keseimbangan dinamis Zero Moment Point (ZMP), kontak   │
└─────────────────────────┴──────────────┴─────────────────────────────┴────────────────────────────────────────────────────────┘
```
