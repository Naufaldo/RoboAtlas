# Prinsip Dasar & Arsitektur Sistem SLAM (MDPI 2025 Review)

> "Bagaimana robot dapat membangun peta lingkungan yang belum pernah dilihatnya, sementara ia sendiri membutuhkan peta tersebut untuk mengetahui di mana ia berada? Inilah paradoks 'Ayam dan Telur' dari SLAM."

**Simultaneous Localization and Mapping (SLAM)** adalah teknologi kunci yang memungkinkan agen otonom menjelajahi lingkungan asing (*unknown environment*), melakukan estimasi posisi dan orientasi secara *real-time*, sekaligus merekonstruksi peta spasial 2D/3D yang konsisten secara global.

Berdasarkan kajian literatur terbaru (*World Electric Vehicle Journal / MDPI 2025*), arsitektur modern sistem SLAM berbasis sensor LiDAR, Kamera, dan IMU tersusun atas 4 modul inti:

## 1. Empat Modul Arsitektur Sistem SLAM

```text
┌─────────────────────────┐     ┌───────────────────────────┐     ┌────────────────────────────┐     ┌─────────────────────────┐
│ 1. Front-End Matching   │ ──> │ 2. Loop Closure Detection │ ──> │ 3. Back-End Optimization   │ ──> │ 4. Map Construction     │
│ (ICP, NDT, LOAM Point   │     │ (Scan Context, Global     │     │ (Factor Graphs, GTSAM,     │     │ (Occupancy Grid,        │
│ Cloud Registration)     │     │ Descriptors, Deep Net)    │     │ Ceres, Pose Graph L-M)     │     │ OctoMap, Surfel, Point) │
└─────────────────────────┘     └───────────────────────────┘     └────────────────────────────┘     └─────────────────────────┘
```

1. **Front-End Scan Matching**: Menghitung estimasi perubahan pose relatif antarkerangka data (*inter-frame odometry*) menggunakan algoritma registrasi awan titik (ICP, NDT, atau fitur kelengkungan LOAM).
2. **Loop Closure Detection (*Deteksi Siklus Tertutup*)**: Mengidentifikasi apakah robot telah mengunjungi kembali area yang sama di masa lalu untuk menambahkan kendala global (*global loop constraint*) dan mencegah akumulasi galat tak terbatas.
3. **Back-End Optimization**: Mengoptimalkan lintasan historis robot secara global dengan meminimalkan galat seluruh kendala graf (*Factor Graph Non-linear Least Squares*):
   $$\min_{\mathcal{X}} \sum_{(i,j) \in \mathcal{E}} \|\mathbf{z}_{ij} - h(\mathbf{x}_i, \mathbf{x}_j)\|_{\mathbf{\Omega}_{ij}}^2$$
4. **Map Construction (*Pembangunan Peta*)**: Menghasilkan representasi lingkungan yang dapat digunakan untuk perencanaan gerak (Grid 2D, OctoMap 3D, Mesh, atau Peta Semantik).

## 2. Komparasi Sensor Utama dalam SLAM (Tinjauan MDPI 2025)

```text
┌──────────────────┬──────────────────────────────────────────┬────────────────────────────────────────────────────────┐
│ Sensor           │ Keunggulan Utama                         │ Kelemahan / Keterbatasan                               │
├──────────────────┼──────────────────────────────────────────┼────────────────────────────────────────────────────────┤
│ 2D LiDAR         │ Cepat, murah, ideal untuk robot indoor   │ Tidak memiliki informasi ketinggian (sumbu Z)          │
│ 3D LiDAR         │ Rekonstruksi 3D akurat, kebal cahaya     │ Mahal, data sangat masif, rentan cuaca kabut/hujan     │
│ Kamera Monokular │ Sangat murah, tekstur visual kaya        │ Skala metrik tidak diketahui (Scale Ambiguity)         │
│ Kamera Stereo/D  │ Menghasilkan data kedalaman instan       │ Rentan pencahayaan ekstrem & area minim tekstur        │
│ IMU (Inersial)   │ Frekuensi tinggi (100-1000 Hz), mandiri  │ Drift integrasi kuadratik seiring bertambahnya waktu   │
└──────────────────┴──────────────────────────────────────────┴────────────────────────────────────────────────────────┘
```
